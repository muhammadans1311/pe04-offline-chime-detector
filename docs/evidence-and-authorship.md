# Evidence, authorship and publication boundaries

## Ownership
PE-04 is a team project. The supplied board images credit **Ahmed Yehia Mohamed** and **Muhammad Ans**. Specific individual contributions should be confirmed with collaborators before public release.

## Evidence types
| Material | What it can support | What it does not prove |
|---|---|---|
| Latest KiCad screenshot | PCB placement and routing work in progress | Passing DRC, fabrication or functional hardware |
| Older native KiCad source | Existence of an earlier editable project | That it corresponds to latest board screenshot |
| LTspice plots and 36-page report | Earlier independent analog exploration and preliminary simulation values | Verified AD8656/TLV9062 circuit or real hardware |
| Audio spectrogram | Frequency and timing observations for source recordings | Correct ESP32 detection of those sounds |
| Four-file Colab results | Offline development-data feasibility | General accuracy, deployable realtime code |
| Eight-block design guide | Team hardware design intent and component explanations | Completed PCB electrical acceptance |

## Correct language
Use **designed / investigated / simulated / analyzed** for work with documented evidence. Reserve **fabricated / assembled / measured / validated** for dated physical or reproducible test evidence.

## Safety and rights
This university student demonstrator is not a medical or certified safety product and must not replace a smoke alarm. Confirm permission to publish shared university work and third-party SPICE models/recordings before setting the repo public. Maintain attribution of team-derived material and original sources.
